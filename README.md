# 黃金騎士 · The Golden Knight

《黃金騎士》是一款繪本動作遊戲。金毛尋回犬與圓桌騎士團的狗狗同伴一起踏上旅程。選擇騎士、法師或弓箭手，移動閃避、停步攻擊、升級選把戲、營地休息，再挑戰每章頭目。

**[在瀏覽器開始冒險](https://doggy-knight-playtest.quantumprediction.chatgpt.site/)**。首次載入約 66 MB。選角時按「迎戰援軍」，前兩關可各多迎擊四隻稻草人。用 WASD 或方向鍵移動，停步自動攻擊，Esc 暫停。支援觸控拖曳，進度保存在同一瀏覽器。[操作與網頁建置](export/WEB.md)

目前有六章、36 關、四位同伴、12 個基本把戲與四個進化、營地小遊戲、訓練，以及通關後的困難模式與無盡試煉。內容與數值仍在試玩調整中。

接續開發請先讀 [目前進度與下一步](docs/PROJECT_STATE.md)，核對工作分支及 PR；預設分支不一定包含最新開發版。

## 開發版 0.9.0（歷史）

第一章加入三職業各兩條起步路線：守陣／追擊、連咒／踏霧、狙擊／游擊。選擇即取得一級起步把戲及有代價的屬性，之後升級會提示相關搭配，同時保留其他選擇與進化。1-2、1-3、1-5 分別加入補給、練習與哨站抉擇；路線及效果可隨關卡安全點續玩，舊存檔遷移至 v11。規則與限制見 [0.9.0 說明](docs/BUILD_ROUTES_ZH.md)。

896 項回歸及九張實際渲染展示通過。原始 12 組首章機器人試玩有一組未通關、一次原生引擎崩潰，紀錄完整保留；不能據此宣稱平衡完成或達到 9/10。這輪沒有製作新下載包，現有 Windows 包仍為 0.8.1。

## 開發版 0.8.1（歷史）

本版接續軍械工坊、地水火風刻印與共鳴、Q／觸控護陣及首章提示，修正普通／精英稻草人和隊長的近戰預警：先標示衝刺後的實際攻擊形狀，身體完全離開預警便不會被該次揮擊命中；蓄力時不再被其他士兵推走。隊長援兵遵守四隻上限，裝備受擊暈眩保留正確收招狀態。存檔維持 v10。前後對照、已知限制與操作見 [0.8.1 說明](docs/MELEE_FAIRNESS_ZH.md)。

已使用官方匹配模板匯出 Windows x64 EXE，並核對內嵌遊戲內容；尚未做 Windows 實機驗證。這是開發試玩版，不代表達到 9/10。以下版本紀錄中的「沒有新版 EXE」是當時狀態。

## 開發版 0.4.0（歷史）

新增 18 件永久裝備：普通武器／護甲最高 5 級，史詩武器／護甲／寶物最高 9 級。每個職業各有武器、護甲及兩個寶物欄，包含鍛造、兩件套裝效果、頭目掉落與五次保底。從標題「裝備與商店」或營地「軍械」進入，以金幣或遊戲內取得的寶石指定購買。真錢付款尚未接通。

故事模式現在保存關卡檢查點，續玩可還原安全點的等級、經驗、技能、事件效果及配裝；未完成關卡會從頭重開。完整數值見 [裝備與續玩設計](docs/EQUIPMENT_SYSTEM_ZH.md)，檢查紀錄及實際介面截圖見 [0.4.0 驗證](docs/validation/0.4.0/README.md)。本輪沒有匯出新版 EXE，先前下載的執行檔不含本版更新。

## Windows 試玩

下載交付的 `DoggyKnight.exe`，雙擊即可啟動；遊戲資料已包含在執行檔內，無需安裝 Godot。這是 Windows x64 試玩版，目前保留直向畫面與原有章節解鎖流程。

| 操作 | 方法 |
| --- | --- |
| 移動 | WASD／方向鍵；也可按住滑鼠左鍵拖曳 |
| 攻擊 | 放開移動鍵或滑鼠，射程內有目標時自動揮劍、施法或射箭 |
| 職業必殺技 | 忠誠度滿時按 Space，或點右下角劍形按鈕 |
| 同伴護陣 | 貝德維爾同行時按 Q，或點盾牌；留在圈內才有護陣減傷 |
| 暫停／繼續 | Esc，或點暫停按鈕；可重看護陣提示 |
| 選技能、對白、營地小遊戲 | 使用滑鼠點選／拖曳 |

切換到其他視窗會暫停。回到遊戲後先放開移動鍵，再繼續操作。進度與設定只存在電腦本機；關卡中途退出不會保留當下敵人與位置，依原有關卡存檔流程恢復。

本次執行檔沒有數位簽章；Windows 是否顯示警告取決於系統設定。只使用專案擁有人提供的檔案，不必關閉防毒軟體。

## 開發與建置

桌面開發版的路線、事件與升級卡可以用 ↑／↓ 或 Tab 切換，按 Enter 確認。也可直接點選卡片。這組鍵盤操作適用於此分支的原始碼。

- 引擎：**Godot 4.7.2 stable**，一般版，Compatibility renderer。
- 匯入 `project.godot`，主場景為 `game/flow/main.tscn`。
- 完整測試：`tools/run_tests.sh`；可用 `GODOT=/path/to/godot` 指定引擎。
- Windows：安裝對應版本的 export templates，執行 `export/build_windows.sh`；輸出在 `export/build/windows/DoggyKnight.exe`。也可在 Godot 的 Export 中選擇 `Windows Desktop`，匯出 Release。
- Android 與 iOS：見 [export/README.md](export/README.md)。
- 開發合約與歷史：[docs/DEV_PLAN.md](docs/DEV_PLAN.md)、[CLAUDE.md](CLAUDE.md)。
- 本輪接手紀錄：[docs/WINDOWS_HANDOVER.md](docs/WINDOWS_HANDOVER.md)。
