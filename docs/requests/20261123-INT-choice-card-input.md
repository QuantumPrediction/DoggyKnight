# 首章選牌的鍵盤操作

2026-11-23（香港）。以草稿 #24 的 `8859306a2c29769b02c36101d2b6104f4e91358c` 為基準。首章的事件／路線與升級都會暫停戰鬥。兩個選單的正式卡片設為 `FOCUS_NONE`，既有回歸可以直接選指定索引。這輪檢查坐在鍵盤前的玩家能否自己選第二或第三張，再回到戰鬥。

修正前先固定以下比較。以相同 Godot 4.7.2 對同一組正式介面送入視窗按鍵，記錄焦點、選擇訊號及正式流程收到的結果。進入戰鬥與製造選擇機會可以自動化，選牌時須走 GUI 輸入。

- 事件／路線的兩張卡、單張及三張升級卡，在沒有滑鼠的情況下都須能選；上下鍵、Tab／Shift+Tab 只在當次選項間移動。卡片進場動畫及底下原有按鈕不能改變導覽次序。新一批卡從第一張開始。
- Enter 確認目前選項，只發一次。路線卡 0.45 秒、升級卡 0.35 秒防誤觸時間照舊；早按並一直按到時限過後、鍵盤自動重複、前一批卡遺留的放開都不能替玩家作選擇。
- 用正式首章事件及升級流程確認獲得所選路線／把戲並解除暫停。另檢查指標能直接選非焦點卡、觸控範圍與既有安全區、可分辨焦點的框線。提交完整本地回歸。保留失敗與來源指紋，無實機時分開記錄工程檢查與裝置驗收。
- 正式變更限定於兩個選牌畫面的輸入與焦點呈現。沿用同一批選項、抽取、效果、存檔與戰鬥資料。無提示試玩仍留給真正參加者。

實作時另見 Godot 的 `ui_down` 包含手把十字鍵，`ui_accept` 只列出鍵盤。追加同一選單的合成手把正向對照，測向下後按南側按鈕是否選到第二張。亦檢查正式升級時以空白鍵確認會否誤發戰鬥必殺技。手把操作手感及各平台實機仍待驗收。
