# 三職業動作、效果與隨身物件

2026-11-23（香港）。基準是草稿 [#25](https://github.com/QuantumPrediction/DoggyKnight/pull/25) 的 `6254f092a6c18931cb884c5f6d16d0aed713d262`。工作開始時，六個底層跑步幀只輪替兩張圖，普通攻擊四幀也只選用兩張。友方法球、劍光及火花始終選用同一畫格。

- 三職業各有四個可分辨的跑姿和蓄勢、出手、延伸、收勢四個攻擊姿勢。對齊正式揮擊或投射物發射，保留移動取消、左右朝向與原有戰鬥時鐘。
- 友方劍光、法球與命中各有連續畫格。箭尖、法球中心與原飛行位置對齊。敵方揮擊預警和危險幾何維持既有狀態。
- 衛兵長劍、橡木法杖、白蠟木弓與三件寶物須能從工坊實際裝備清單讀到。每個物件在格內有透明邊距，接地動作共用腳底位置。屬性與存檔沿用現有設定。
- 以三職業相同輸入、相同目標比較出手、命中和傷害。保留 1-4 兩條原有的失敗、完整回歸與來源指紋。圖稿示範和原生遊戲截圖各自標示。
- Ubuntu 首次渲染額外發現「緒」不在內置字體。後續只換「起步翻滾已就緒」為「起步可翻滾」。用相同引擎、場景、版面和視窗檢查五對原生截圖，五張候選都須符合既有文字及安全區門檻，保存失敗與對照。
