# INT — 普通稻草人最後可撤離窗口

基準為整合提交 `b05224258e0bdc70cfde7d0cb874a6b36d7f4617`。先凍結首章、普通、弓手、兩路線、seed 19、兩個既有政策與原有報告；四場舊追蹤的間隔是半秒，不能還原一次揮擊內的動作。

唯一候選改動為略為延長普通稻草人揮擊預警。在觀察原版前登記。啟用條件是兩路線上重現預警起始仍在攻擊內、立即撤離也缺乏可行路徑的問題，並能將差異歸因於揮擊時間。若只在個別方向、特定交叉火力或遲反應下失敗，保留原值。任何玩法改動仍須另作凍結的多政策開發與確認驗證。

本輪將獨立記錄每個物理幀及稻草人的鎖向、結算或取消。以各場首個普通揮擊受擊作配對反事實重播，測試已登記的向外步行／側移與延遲輸入；若無受擊則取首個以玩家為目標並完成結算的揮擊。成功要求真實引擎路徑、相同攻擊結算、身體脫離原扇形且介入至結算沒有其他傷害或無敵。有限方向未成功一律列為未證實。僅有成功翻滾及排除步行可能的證據，才可判為必須翻滾。保留失敗試次和來源指紋。參與者人數、實機及品質評分另行驗收。

首輪四場完成後，兩條謹慎路線首個揮擊受擊者在出招時均在扇形外。為直接量度候選改動的適用條件，在補充介入前固定規則：每條謹慎路線取首個「以玩家為目標、開始時覆蓋玩家、當時沒有無敵亦未翻滾、最後實際受擊」的普通揮擊。用相同的三個方向及時刻重播，保留所有原試次。符合規則的是神射 `17585.4` 與遊騎 `18070.1`。
