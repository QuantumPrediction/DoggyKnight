# 首章稻草人弓兵的弓弦與鎖線

基準為草稿 #28 的 `f082bb3de6c919dd5ce2f894f7350d7d2bc7b791`。舊版把兩格瞄準動畫都畫成垂弓待機，放箭後三格都畫成箭仍在弦上的滿弓。這輪只重畫該弓兵的追蹤、鎖定、放手及收弓。保留正式移動、暈眩、倒下、射線、飛箭、傷害時點及 HUD。

- 追蹤與鎖定讀取現有可見直線預警及其 `aim_locked` 位元。箭離弦後才切空弦，收弓取既有攻擊動畫的下一格。空弓不繪製第二支飛箭。停頓不另走美術時鐘。目標移動可以在追蹤時改變朝向，鎖定後仍朝正式射線。正、背面不隨微小的水平移動翻轉。
- 固定第一章農場、騎士與普通弓兵、相機及 360×640 視窗。比較朝右、左、前、後的四次固定站位命中，一次先移動再於鎖定後移出射線的未命中，以及一次鎖線後暈眩中止。同機基準／候選逐物理幀的目標、弓兵、鎖線、箭矢軌跡、命中與活力須逐位元組相同。固定原有亂數種子與擺位。取消後須零發射。
- 原生畫面的待機、取消與回到移動等控制須逐像素相同。有效姿勢差異只准出現在該幀原有角色繪製矩形外加一像素濾波邊。追蹤及鎖線各以同版同幀只關掉該次地面筆墨的畫面相減，任一 RGB 通道差 ≥8/255 計為可見。世界座標沿射線超過起點 24 單位的已可見像素，以及末端鎖線括號，不准少一個。另列靠近弓兵的新增或被遮住像素。人物鎖定後移動、連續放箭、暈眩、其他敵人及隱藏警示均要有邏輯對照。
- 若判定或外段警示不符，先記錄失敗，再收窄輪廓或撤回正式綁定。保留來源圖、每格範圍、指紋及原始失敗。沒有真人及手機實測時，維持未驗證。
