# 戰場寶箱的箱形與開蓋

基準為 #26 的 `b413b36bd47e8cb614210d3d714ee5154be0d5bf`。普通、精英、頭目共用同一個箱形。舊繪本層把全部 `open` 幀都映射到已打開的圖。這一輪只替換戰場寶箱的插畫。

- 普通箱用平蓋和骨扣，精英箱用削角和盾扣，頭目箱用拱頂和王冠。三者各有合蓋、微啟、半開、全開四格。兩個待機幀都應合蓋，開蓋三格只由原有 SpriteFrames 的三個幀觸發。
- 固定 Godot 4.7.2、60 Hz、第一章農場及正面鏡頭，比較相同輸入下三個正式掉落物的入場、拾取、開蓋、淡出及移除。任一等級的收集事件次數、觸發幀、位置、動畫時序或存活時長不同即退回。
- 遊戲圖集須有十二張不重複的畫。每格透明邊至少四像素，同一箱子的底緣在一像素內共線，開蓋輪廓依序升高。保留原 24×24 世界繪製矩形、掉落光柱及地面光圈。
- 360×640 固定鏡頭分別看落地與拾取。記錄被英雄、粒子或介面遮住的時點。若無真實 framebuffer，保留此項待驗；圖集動作示範可獨立檢視。人類辨認三個等級仍須用無提示試玩驗收。
