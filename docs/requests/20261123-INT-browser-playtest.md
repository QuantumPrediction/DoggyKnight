# Browser playtest of the full game

Use the game and art from the current archer-motion branch. The owner requested a browser version for potential players to open by link. Use the existing title, class selection, story, combat, checkpoints and touch controls.

The package is accepted when Godot can load all six chapters and four companions from the exported pack, and a browser can enter a fresh adventure through the regular controls. Check the desktop keyboard prompts, pause, a saved checkpoint on reload and the message when WebGL 2 is unavailable. Check anonymous access at the published URL separately. Record the full regression result and known warnings.

Use the same gameplay sources for future mobile exports. Limit front-end adaptation to loading, viewport presentation and input hints. An observed browser session counts as engineering verification. Physical devices and uncoached participants retain their own acceptance criteria in the [trial instructions](../validation/scene-lifetime/archer-trial.md).
