# 1-4 固定介面底板與預警外框的配對門檻

起點固定為 [PR #22](https://github.com/QuantumPrediction/DoggyKnight/pull/22) 合併 `d9188279e0b4720dd35b7b7532f42a9dbb6f4b8e`，tree `13415a50ebb70983e623f42c2aeabc79e3a3eec0`。兩個既有外框與不同固定底板相交。只測一個假設：降低底板對底下原有外框的遮蔽，是否能在兩處都增加外框對比，同時保住前景文字、圖示及操作範圍。本包只交付驗證工具；正式 HUD 候選待有相符的原版渲染後另試。

用原 seed 19、cautious/reactive、兩條路線原裝備、60 Hz 及 Godot 4.7.2。每版本各錄正常畫面及只在算繪層關掉所選預警的對照。後者僅用於量測。工程條件以 #22 的 70 個正常 PNG、兩份完整戰報和兩份完整逐幀記錄為準。每幀要求一次完整更新、兩種渲染模式的角色／扇形／相鄰攻擊／教學／控件幾何／前景狀態相同；新舊正常畫面的改動限於兩個底板矩形內。每個版本的兩遍重播須為同一來源，顯示環境必須一致。

沿每條正式外框邊約每畫素取樣，去除端點三畫素。取邊上及法線正負三畫素的兩個鄰點，三點都在目標框內才納入。對每個 RGB 通道，以「正常減去移除所選預警」得到歸因於該預警的訊號，再取邊點與兩側鄰點的差；同一通道兩側同向、最小邊差至少 16/255 才計入。每個主要驗收幀，候選至少淨增三個通過的取樣位置，缺樣、任一幀未達標、資料不齊或守則失敗均不得通過。此門檻是工程判準，並非人眼閾值。所有幀及失敗要保留，兩個場景不可相互抵銷。調整門檻須另開登記。

另須看並排正常原畫，核對按鈕外形、圖示、警示三角、進度條及文字清楚程度；即使量測通過亦須獨立覆核。傷害、受擊幀、敵人、AI、按鈕熱區、安全區、存檔及 #22 成功卡時序均不變。回退僅涉及測試、工具及文件。既有倒下、角色／特效遮擋及缺乏真人資料均保留。
