# 黃金騎士的起步、轉向與收步

起點是 #31 的 9b7ed6c449087ae8a89daea997fcecde707b085e。這輪以同一角色、輸入、場地、固定鏡頭及 360×640 畫面比較。請美術與測試線各自保留原始對照。

* 角色線讓腳步跟隨角色在地板上真正走過的距離。比較由靜止起步、半速與全速、反向煞停、推牆、向前／後收步及中途發動攻擊。反向後仍在原方向滑行時，腳步應保持原方向；穩定貼牆期間不得繼續輪播跑姿。在相同地面距離下，半速與全速的步數差距以一個姿勢為限。
* 美術線為三職業各畫正面及背面的落腳、站穩，腳底配準原有地線。由跑轉停時應維持視角，武器不可突然換手。檢查原尺寸及遊戲內實際大小。
* 名稱統一為「黃金騎士」和「The Golden Knight」。沿用原有試玩連結，舊存檔須可讀。
* 角度、速度與時機取自正式移動。逐幀比對物理位置、攻擊及輸入結果；留存不合格樣本。翻滾與攻擊即時回到正式動作。若程式或壓縮成品未通過驗證，先修正再發布。
* 本輪以美術與動作呈現為界。既有敵人增援、傷害字級及開場選擇均是玩家正在試玩的比較條件。手機幀時間、真人對動作與預警的判讀、長局及市場成績仍需另外量度。
