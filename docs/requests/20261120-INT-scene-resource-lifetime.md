# 關卡特效與配樂的資源生命週期

接續 PR #17 的公開版本 `70dc412ab8e1ac330e7ecfa57cd1581ddba06f62`。標題單獨執行的退出紀錄列出標題曲。三次真實進出關卡後的紀錄另列出田野配樂、鼓點、動畫幀與粒子場景。引擎固定為 Godot 4.7.2。

- 在正常播放、轉場、暫停調低音量、靜音及快速換曲下追蹤音樂播放器與音樂資源。驗證章節配樂可於淡出後回收，播放中的主旋律及節奏音軌仍能完整過渡。
- 讓戰鬥特效在同一場地內重用。以兩個同時存在的正式場地驗證彼此獨立，以及最後一個使用者離場後的回收。
- 在改動前保留行為測試失敗。前後各測標題單獨退出、三次詳細進出及一百次「標題 → 正常關卡 → 暫停 → 返回標題 → 釋放場景」。保留退出訊息與固定條件的弓手戰鬥對照。
- 跨戰鬥、音樂及整合測試。範圍包含製作用的弓手 1-4 無提示試玩準備。問題紀錄要區分專案實際持有的資源、混音器／引擎退出訊息，以及歷史上那次尚待重現的原生崩潰。
