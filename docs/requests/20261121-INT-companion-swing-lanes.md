# INT — 1-4 同伴方向的揮擊：進入扇形前的配對重播

凍結基準：已合併 PR #19 的 `7d63fffd4ca455837899679ca4b125b030f1f4b3`。本輪只改測試工具，不改正式預警、傷害、出招時間、UI、敵人、數值、關卡、存檔或既有 bot。問題是：原路徑走進同伴方向的揮擊前，停輸入或側移能否避開相同攻擊，且不撞進另一攻擊？

## 樣本與操作先行鎖定

- 只用 #19 的普通難度、第一章、兩條謹慎弓手路線、seed 19。從 `swings.csv` 選有實際普通揮擊傷害、起初不覆蓋弓手、瞄準同伴、該次預警期間曾有至少兩個正式預警覆蓋、且未在 #19 的 `forks.csv` 介入過的（案例、攻擊編號）。
- 神射取最後進入距命中不超過 3 幀的最早一例，遊騎取至少 14 幀的最早一例，按起手幀再以攻擊編號排序。固定為神射 `20980.1`（第 29 幀進入、第 31 幀命中）及遊騎 `17197.2`（第 9 幀進入、第 31 幀命中）。全部數字從舊記錄讀出，不以新結果重選。
- 原操作不改。各例在最後進入前一幀與再早 6 幀（神射 28／22、遊騎 8／2）各試三種輸入：鬆開移動（正常減速）、相對扇形方向向左／右側走。共 12 次介入，不補挑其他延遲與方向。第 d 幀末送出的輸入從 d+1 幀起生效。

## 成功標準

先逐位元組重現兩份完整戰報及 #19 逐幀記錄。每次介入須在完全相同的已記錄前綴出發，並對齊相同攻擊編號、命中時刻、扇形原點與方向。記錄介入後至該幀結束的真實碰撞與所有傷害來源，而不是只量被選的扇形。有連續跑動、翻滾或角色無敵仍須如實標註；不得把翻滾輔助寫成普通步行，或把雖避開選中揮擊但中了別的攻擊寫成成功。保留每條路徑、失敗與來源指紋。沒有找到可行輸入不等於無法躲避。
