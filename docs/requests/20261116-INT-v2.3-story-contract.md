# v2.3 故事與深化合約

- 提出:整合工作階段,2026-11-16(擁有人問故事、敵人難度與畫面,並要求再深化)
- 狀態:已完成(擁有人授權整合工作階段自行決定並推進)

## 要改甚麼

1. **範圍變更**(擁有人要求):
   - 加入完整的第一章故事:頭像對白與繪本插畫,不做動畫過場。
   - 小怪新增稻草人弓兵、空盔甲兵;1-4 新增中頭目稻草人隊長。
   - 新增困難模式。
2. EventBus 新增 `boss_appeared(enemy_id)`、`dialogue_started(script_id)`、`dialogue_finished(script_id)`。
3. `GameState` 新增 `difficulty`、`chapter_cleared`、`story_seen`;`reset_run()` 不會重設。
4. 新資料類別 `DialogueLine`、`DialogueScript`;`LevelData` 新增 `story_before`、`story_after`。
5. 新增 `docs/STORY.md`(故事設定與全部對白)、`i18n/story.csv`(登記為翻譯檔)、對白框初版,以及頭像、插畫、新角色圖、投射物的佔位版。
6. DEV_PLAN 新增 4.11 與第 16 節。

## 為甚麼

- 擁有人問「故事夠不夠好玩」:原計劃沒有故事,只有關卡名稱,玩家沒有動機,也沒有結局。
- 擁有人問「敵人是否太容易」:試玩機器人整章從未倒下;只有近戰小怪,沒有需要不同打法的敵人。
- 擁有人問「畫面是否太簡單」:沒有頭像、插畫、光影與景深。
- 故事由整合工作階段統一撰寫,四條線依同一份文件實作,角色與語氣才會一致。

## 影響哪些線

四條線都要讀 DEV_PLAN 4.11、第 16 節與 `docs/STORY.md`。改動都是「新增」,沒有更改或刪除既有的合約。
