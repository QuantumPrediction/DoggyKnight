# 第一場戰鬥的走位、停手與第一招

以 #32 的 5ac568a2f118deb07730f50fd68a0c2fd7a1f3a9 為控制。舊搖桿一過 2.5 邏輯像素就全速，半徑為 18。首關舊教學要拖 20 才換提示，在敵人附近放手、任一敵人倒下或等四秒都可能獲得「做得好」。本次只改十字鍵／觸控共用的移動教學與浮動搖桿的短行程精度。

- 觸控輸出以拖距決定移速。2.5 內為零，9 時須在全速的 48–52%，半徑的 85% 起全速，各方向一致。移動向量與角色朝向分開，保留滿幅方向、攻擊／受擊時點、翻滾從開始移動觸發、防禦冷卻與按鈕熱區。
- 三職裸裝對固定普通稻草人，以基準與候選各做同一套測量。起點在各職命中範圍內 12 單位，分別半幅及滿幅走 16 格，再鬆手等 60 格。半幅須三職皆能停在 9±3 單位、拖動時不出招、放手後造成實際傷害。滿幅同時長的失敗與滿幅只走 8 格的成功都須保留。另測斜向、微動、阻擋、取消與第二指，留下所有結果。
- 首關要在真正移動後才切到停步提示。三職自己的普通攻擊出手才顯示完成鼓勵；只放手、同伴擊倒敵人、四秒逾時均不算。逾時以中性方式退場，沿用原有結束、清場及舊存檔行為。教學算作看過與玩家學會是兩筆不同事實。
