# 合約變更申請

`core/`、`project.godot` 與合約(DEV_PLAN 第 4 節)已凍結。需要修改時,任何一條線都可以在這個資料夾新增一個申請檔,然後**繼續做不受影響的部分**,不要等。

流程:提出申請 → 擁有人決定是否接受 → 整合工作階段統一修改 → 申請檔的「結果」欄更新。

## 檔名

`YYYYMMDD-<線>-<主題>.md`,例如 `20261120-D-ios-audio-session.md`。

## 範本

```markdown
# <主題>

- 提出:<A / B / C / D> 線,<日期>
- 狀態:待決定 / 已接受 / 已拒絕 / 已完成

## 要改甚麼

(具體的檔案、訊號、欄位或專案設定;如果是 project.godot,寫出設定名稱與數值)

## 為甚麼

(不改會怎樣;有沒有不用改合約的替代做法)

## 影響哪些線

(哪些線要跟著改程式;估計工作量)

## 給擁有人的一句話說明

(不用術語,說明這個改動對遊戲有甚麼好處)

## 結果

(由整合工作階段填寫)
```
