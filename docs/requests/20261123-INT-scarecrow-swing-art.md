# 普通稻草人的揮擊

基準為草稿 #27 的 `334fd00d8cfcfa4c68ff04d2bcac4f2899216511`。現有近戰兵在揮擊警示期間播放待機畫，揮出期間只顯示一幅插畫。這輪只畫普通稻草人的起手、繃緊、揮出和收叉。精英、弓兵與隊長各自保留目前畫面。

- 起手跟隨已存在的有效扇形，繃緊跟隨同一扇形的 `is_hot()`，揮出跟隨真正的 SWING 與 attack 第 0 格，收叉跟隨同一原動畫下一格。中斷、受擊、死亡及一般走路須保留原有表現。
- 插畫面向已鎖定的方向。測右、左、朝向鏡頭、背向鏡頭，另做預警中途取消、精英對照。不能改變方向、計時、位置、傷害、受擊形狀、存檔、HUD 或觸控熱區，不能增加獨立動作時鐘。
- 以固定的第一章農場、正式場地及敵人、同一騎士位置與 60 Hz 輸入，比對物理事件、受擊、扇形輪廓、角色與鏡頭。滿足以下條件才保留正式綁定：同機前後追蹤逐位元組一致，測到取消時不顯示揮出，陰性對照畫面相同，全部插畫留透明邊，沒有顛倒左右或前後。
- 在 360×640 原生畫面以舊、新兩版各自的「顯示扇形／只略去扇形筆墨」做成對比較。地面扇形遠端外弧的可見像素數若減少，就收窄該姿勢或退回，不用改變地面警示補救。固定擺位、可見像素及真人看懂攻擊分開記錄。

原生渲染前固定量度法：用正式扇形外弧的十段折線，取像素中心距折線 1.5 px 內的區域。比較同版同幀的有墨與無墨圖，任何 RGB 通道相差至少 8/255 算為一個可見外弧像素。逐張記錄新出現及消失的像素，要求舊版可見的外弧像素全部保留。另量整幅扇形筆墨的增減，供觀察近腳側邊。四方向每案另以收招、傷害與原有動畫幀核對時序。
