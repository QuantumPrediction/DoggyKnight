## 本輪變更

1. 新增 WASD／方向鍵移動，斜向速度與直向一致；放開後沿用原有自動攻擊。
2. Space 觸發原有必殺技；保留忠誠度需求，暫停時不觸發，長按重複事件不觸發。
3. 暫停或失去焦點後，按住的移動鍵要先放開再按，避免恢復時意外移動。
4. 電腦版教學與暫停選單顯示鍵盤操作；觸控路徑繼續可用。
5. 預設視窗改為 360×640，方便在一般筆電畫面內試玩。
6. 新增 Windows x64 Release 匯出，將遊戲資料嵌入單一 `.exe`；排除測試、工具、商店草稿與開發文件。
7. 新增可重複執行的建置腳本與專案 README。

## 驗證

原始提交在指定引擎下執行完整測試：770 項通過，0 失敗，0 損壞檔案。原版測試結束時已有資源未釋放的警告，不能稱為完全沒有警告。

本輪完整回歸：**776 項通過，0 失敗，0 損壞檔案**。新增的六項測試使用真正的鍵盤輸入事件，涵蓋方向鍵、WASD、斜向速度、放開後攻擊、暫停保護、必殺技及鍵盤教學。退出時的資源警告數量與原版一致。

Windows x64 Release 匯出成功；核對為 PE32+ GUI 執行檔。從執行檔內的遊戲資料包以 Linux 上的同版本 Godot 啟動主場景，另逐一載入 36 關與四位同伴，確認測試場景被排除；桌面暫停面板為 154×254，放得進 180×320 基準畫面。`export/build_windows.sh` 已包含資料包檢查。這些是跨平台內容檢查，不能視為 Windows 原生執行或顯示卡驗證。

## 接下來的開發方向

先收集這個原版的試玩回饋，再做一個可與原版比較的 Steam 核心玩法切片。優先測試「丟出、尋回、爆發」與同伴合作是否比原本的停步攻擊更有辨識度；目前它是設計假設，尚未整合進本次版本。其後再決定橫向介面、完整控制器支援、難度與成長節奏、多語言、美術重製及 Steam 功能。

不要以新增內容數量或自動測試數量宣稱遊戲好玩；也不保證 Steam 排名或銷量。現有章節平衡仍以自動試玩資料為主，需要真人試玩確認。
