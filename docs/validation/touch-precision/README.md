# 輕推後撤，放手時仍能打中嗎？

同一個 16 幀手勢，#32 的半行程和滿行程讓三個職業走得一樣遠，都退到稻草人射程以外。候選把半行程變為 50.78% 的移速。這次三職都停在預定的後撤區，放手後各自用平常的武器打中。舊版玩家也能用更短的滿行程手勢做到，這個正向對照兩版都成功。

## 預先固定的比較

搖桿半徑為 18、死區為 2.5，單位都是 180×320 遊戲座標。基線與候選均在 360×640 視窗，把相同的 `InputEventScreenTouch` 和 `InputEventScreenDrag` 送入正式 viewport 的輸入流程，由場上的玩家接收。不呼叫角色移動替身。右向、斜向都用同一持續時間，檢查死區、半行程、外圈、放手、第二指和移動鎖定。半行程須明顯低於全速，外圈、鍵盤全速和放手自動攻擊須保有原有行為。

戰術任務採正式場地、角色及普通稻草人。三個基礎職業各自從 (136, 160) 起步。稻草人站在左方，其中心與玩家相距「該職業的索敵半徑 + 稻草人的實際身體半徑 − 12」，故往右再走 12 個單位便到最外射程。稻草人固定位置並停用自主移動，角色照常加速、煞停、索敵、揮砍或發射投射物。玩家向右拖 9 或 18 單位，維持 16 個物理幀後放手，再觀察 60 幀。另以全行程維持 8 幀作正向對照。每種手勢都從新的場地開始，暴擊亂數固定為 19。

事前的成功條件是停在距起點 9 ± 3 個單位的區間，拖動期間不發動攻擊，放手後實際扣除目標生命。未達其一即保留為失敗。停止區的邊界及手勢時長在執行基線和候選前訂定。

## 移動和翻滾的界線

- 在 2.5 單位時角色靜止。3、6、9、12、15 單位分別量到約 3.91%、27.34%、50.78%、74.22%、97.66% 的指令速度。9 與 18 單位按 (0.6, −0.8) 斜移，與持續時間相同的直移相差少於 0.0004 世界單位。關於幾乎朝正上方的左移，6 單位輕推仍保持完整朝向並切至朝左圖像。
- 外圈名義上從 15.3 單位（85%）全速。從觸點 x=28 輸送這個小數座標，兩版位置逐幀相同，速度最大差異為 0.000008 單位／秒。16、18、27 單位、鍵盤全速、貼牆、滿桿翻滾和射程對照等共十二組，三職合計 1,665 筆，全部儲存欄位相同。
- 第一指保持所有權，第二指的拖動和鬆手不會改變速度指令。回中心可在仍按住時煞停。取消觸控、暫停後恢復、從真正的暫停按鈕開始拖動、角色倒下後再次觸碰都沒有留下移動指令。暫停期間角色位置凍結，恢復後沿既有減速曲線停下。
- 已學翻滾時，半推和滿推均在 t0–17 受保護，t179 冷卻歸零，t188 再起步能再次翻滾。輕推換來較短走位。在首 18 幀中，騎士半／滿推走 15.59／29.17，法師 15.15／28.33，弓手 17.38／32.50 個單位。須逃離遠端警示時，半推的位移會較短。這次沒有測量有多少玩家能判斷所需力道。

## 證據與重現

每版取樣 3,291 個物理幀，Linux x86_64、Godot 4.7.2.stable.official.ed1daf0bf、headless、60 Hz。每版在兩份獨立空資料目錄各執行一次，逐幀檔及各情境總表各自逐位元組相同。兩版四次退出均列出 6 個 ObjectDB 物件與 2 個 resource 仍在用。此結果不驗收退出問題、網頁或手機觸控延遲、裝置幀時間、觸控主觀手感或真人成功率。

[基線各手勢](before/trials.tsv) · [候選各手勢](after/trials.tsv) · [來源、引擎、重跑指紋與退出訊息](provenance.json)

`tick` 從手勢第一個物理步算為 0，`physics_step` 從場地預熱完算為 1。只在 ownership 情境安裝真實 HUD 時留了兩個空白步。座標、向量和速度記至小數點後六位，`-1` 代表對應事件或目標不存在。輸入原點為 (28, 228)、第一指索引為 3、第二指為 7。除具名的鍵盤對照外，沒有模擬鍵盤輸入。

取得 #32 提交 `5ac568a2f118deb07730f50fd68a0c2fd7a1f3a9` 及本候選，各以相同引擎完成資源匯入。從候選根目錄執行下列命令，`BASE` 為已匯入的基線 checkout 路徑。測量工具和輸入序列兩版共用。

```sh
RUNNER="$PWD/tools/measure_touch_precision.gd"
WORK=$(mktemp -d)
XDG_DATA_HOME="$WORK/profile-before" TOUCH_PRECISION_DIR="$WORK/before" \
  godot --headless --path "$BASE" --fixed-fps 60 --script "$RUNNER"
XDG_DATA_HOME="$WORK/profile-after" TOUCH_PRECISION_DIR="$WORK/after" \
  godot --headless --path "$PWD" --fixed-fps 60 --script "$RUNNER"
python3 tools/compare_touch_precision.py "$WORK/before" "$WORK/after"
```

公開檔案提供每種手勢的可讀總表、全部成敗、程式與 SHA-256。兩份完整逐幀壓縮檔保留本地。重新產生後可用 `sha256sum "$WORK"/{before,after}/{ticks,trials}.tsv` 和 provenance.json 的 repeat_1 比對。首次未先讓新場地加入 viewport 的試跑發現主手指未被接收，測量器已加上預熱和手指所有權檢查。匯出欄位格式不完整的除錯輸出也在封存前排除。此處只以真正接收事件、欄位齊全且可重現的配對比較。

## 首關教學與全速玩法對照

首關從實際位置與已接受的移動輸入判斷走位，累積移動一個遊戲單位才提示停步。鼓勵取自角色的普通揮劍、放箭或施法次數增加，出手與命中分別記錄。四秒戰鬥時間內沒有出手，提示安靜淡出，暫停凍結計時。看過提示沿用原有存檔欄位。第二指、待機或其他來源擊殺怪物不會獲得鼓勵。
