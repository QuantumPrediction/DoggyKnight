## 觀測與重播

- `begin` 在正式攻擊確定預警原點後發出。`impact` 在扇形判定傷害前同步發出，直接使用該次判定的玩家身體半徑。取消、傷害與出招分開留存。編號為固定出生 RNG 覆寫值與該敵人的攻擊序號，不能當作跨路線的同一敵陣。
- 每個 `frame` 取自所有角色物理更新之後。記錄 `p` 的位置、輸入、速度、加減速時間、停步／翻滾狀態與可到邊界，`paused`、戰鬥時間倍率、所有普通出手編號及移動敵人。敵人陣列依次為出生種子、類型、位置 x/y、速度 x/y 與狀態。預警陣列依次為形狀、原點 x/y、方向 x/y、半徑、半角、長度、寬度、進度、追蹤中、覆蓋玩家。飛行中的投射物沒有地面預警時仍可造成傷害。
- 在出招幀後第 0、15、24、30 幀，重開一個隔離存檔，從章首重現到同一狀態，換成固定方向直至結算。向外為介入時玩家相對預警原點的方向，兩側為已鎖揮擊方向的兩個垂直方向。第 d 幀結束後寫入，玩家物理更新在 d+1 首次消耗該輸入。每案從最遲成功普通步行的抽樣方向，逐幀補測其後所有未試時刻；已到第 30 幀的成功例毋須補測。其他方向及組合輸入不作全域不可達宣稱。
- 成功的普通步行要求該次揮擊確實結算、身體在扇形以外、介入到結算幀結束沒有任何傷害、滾動或無敵。另記介入時已在扇形外、翻滾輔助與失敗；前者不能算作從扇形內脫離。每一重播完整保留真實其他敵人與傷害來源。
- 四份 `archer_*.jsonl.gz` 保存原始對照；`fork-paths.jsonl.gz` 的每段以 `op=trial` 與後續原始位元組長度開頭，接著是該分支從介入幀至結算的完整資料。`forks.csv` 含匹配的原對照前綴行數與 SHA，以及分支資料 SHA。最早的工具錯把暫停幀略過，神射謹慎有四個不同物理幀、影響五次揮擊；完整性檢查拒絕該次結果。修正後 714 次均可逐幀續接。[被拒絕的原始追蹤](rejected-paused-frames.jsonl.gz) · [缺幀與來源指紋](rejected.json) · [引擎與測試日誌](run-logs.jsonl.gz)
