## 比較與已知缺口

基準為草稿 #30 的 d2e9b2b3443cbe1ff1ca3d45f597fe3cdcd5ff98。一般開局與自選援軍分開記錄，以免把更密的編隊當成所有玩家都想要的難度。原先三個強制加兵的候選曾造成新的三倒失敗。第一次將自選隊伍與必出隊伍放在同一資源陣列，也讓普通關卡的時間估算及擊倒總數回歸測試失敗。正式資料改以各波獨立的援軍欄位保存；星數指標仍以原有必出隊伍估算。詳見[原始條件與失敗門檻](../../requests/20261124-INT-opening-playfeel.md)、[逐組戰報與重跑方法](pacing/README.md)。
