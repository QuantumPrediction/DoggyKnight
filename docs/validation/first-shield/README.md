普通模式從全新標題按「開始冒險」起算。以三職業、種子 7 及 19、第一張路線卡配對比較。#33 的六場原定回應都要到 1-3、131.62–148.52 秒才出現第一次正式護陣反擊命中。最終候選同六場在 1-1 於 29.87–34.27 秒完成。敵人在場且實際可下盾指令的時間由 124.35–145.98 秒提早至 25.25–30.72 秒；傷害預警與玩家身體第一次相交為 26.90–32.18 秒。五場先攔到正式箭矢、一場先減輕實際傷害，再以普通攻擊命中。

最終版依指引的六場中，第一次普攻反擊都由護陣減傷觸發，時間為 26.95–32.28 秒。不按盾的六場有一場盾犬被動攔箭，六場均未收到反擊蓄力。最終版借盾與預設各 18 場都打完 1-3，正式盾犬仍在 1-3 入場。預設的 18 份完整觀察與 #33 逐欄相同，唯一新增欄位是「看見借盾選項」及其計數。工程時計未量真人首次發現、閱讀或執行成功率。目標玩家仍為 0 人。

首版保留法師真擋箭、蓄力過期的場次，也保留弓手瞄準後死亡、全程零發箭的情況。第二版中，法師 19 及弓手 7／19 仍能在敵弓手放箭前擊倒它；原定與明示政策都未在這三組打出首關反擊。最終陣形保留首次明示、實際減傷、被動攔截等不同經過，表中成功數限於真正由普攻命中消耗的反擊。凍結的普通路線比較共 90 份完成報表，另有首版第二張卡片的六份先導報表。早期量測的兩宗原生中斷、四個另存的重跑及已知離場警告見 [引擎記錄](engine/README.md) 與 [檔案指紋](checks.json)。

## 執行前登記

固定基準草稿 #33 `53b07837d21c4cd7f0178992f73779092e49389c`，Godot 4.7.2、60 Hz、正常難度、新的獨立存檔、無購物與訓練。第一輪用種子 7、三個職業；另留種子 19 確認。每組從標題「開始冒險」的按鈕計時，用正式選角與出發按鈕，立刻略過可略過的對白、依既有撤離政策走位和選把戲。計時包含選單轉場及暫停，屬模擬時間。真人閱讀、找按鈕與猶豫無法由這個時計估算。

至少比較看見威脅後呼喚並停步的政策，及不使用盾、照常戰鬥的政策。為兩版固定相同輸入規則、記下每次失敗、三倒或時間上限。若有明示的可選入口，另外保留不選它的正常通路。

- 同伴到場、HUD 盾可用、真傷害預警與玩家交疊時可呼喚，分開記錄。排除登場圈、隱藏、已排隊刪除的警示與純裝飾。預警位置只是一個可反應的候選時點。
- 真正攔截來自 EnemyProjectile 的 block 事件。近戰保護計 Bulldog 的實際減傷計數，不把同伴自行受擊記作玩家受到保護；另列反擊蓄力的 granted 以及 resolved 的 used / expired / cancelled。
- 本輪若改早期機會，三職指令政策都須在較早的關卡取得真實合作；天然樣本只出現標記／按鈕、沒有擋下、沒有實際普通反擊要逐項列為未達。另核對未呼喚、閃避、倒下與正式正常通關的原始結算。純自動防守與玩家主動合作分別記錄。

## 追加的明示操作對照

首輪兩種子：騎士兩場在新首關均真的擋箭並命中，法師一場蓄力過期、一場沒有攔下；弓手一場按盾未取得反擊，一場未碰到可呼喚的交疊警示。保留原資料。第二個回應策略按照選中後的指引，看見站穩的敵弓手就走向它，直到接近兩個身位。看到真正開始的箭線便面向弓手呼喚並停下，不要求箭線已經掃到玩家。若獲蓄力，走向最近的可攻擊敵人，在自己的攻擊範圍內停下，等待正式普攻。這套策略不讀種子、敵人出手倒數、未出場位置或怪物未來軌跡；兩版、三職、兩種子共用。分別記下「看見箭線」及「預警與身體相交」，與首輪分列。

## 讀取紀錄

- `normal-trials.tsv` 每場一列。時間單位是「關卡@標題開始後第幾個 60 Hz 物理步」，`-` 代表觀察截止時仍無該事件。HUD 可按、已有敵人且可實際下令、碰到身體的警示、在已發射真箭前方、真正擋箭、玩家真實減傷、獲蓄力、普攻命中消耗，均獨立記錄。已發射箭的最遠直線與此刻玩家重合，只表示若雙方情況不變會相交。被動擋箭及主動下令可在事件欄區分。
- `contacts.tsv` 逐個列出三房內同伴入場、呼喚、攔截、減傷及所有反擊結果；`archers.tsv` 列出首關試煉所有弓手從真正入場到離場的瞄準、每一支已發射的箭、碰撞或被擋。玩家在警示尚未結束前擊倒弓手的場次仍算入分母。每支箭的末欄格式為「發射步數:被擋 0/1:擊中數」。
- `rooms.tsv` 保留每一房的勝負、擊倒數、玩家受傷、正式戰鬥秒數和離開時的物理步。`engine/` 保留兩次原生中斷及重跑資料。每場原始 JSON 的 SHA-256 與表並存，供重新執行比對。
- 固定藍本使用 Linux Godot 4.7.2、普通難度、各職第一張卡片的正常路線、無訓練和裝備。自動輸入從標題選「開始」，12 步後選職業，另 12 步後選「普通出發」。選路線等淡入與正常防誤觸結束再點按。略過對白、選升級；在營地執行既有小遊戲流程。步速 `1×`、固定 60 Hz，headless 在牆鐘上可快於真實遊玩。時間不含載入程式與標題停留、真人讀字及思考。
- `skip` 全程照既有 escape 政策移動，不呼喚護陣。`call` 等帶傷害的扇形／箭線真正交疊玩家，面向對手、按盾並最多停 96 步；得到蓄力後回到一般走位。`follow` 使用已選盾牌卡片的面向、看箭線按盾與接近後停步操作。路線、借盾及實戰按鈕經遊戲 viewport 的按下和放開；移動、升級和小遊戲沿用專案測試入口。它們皆為自動操作。
- 減傷只計算 Bulldog 的 `protect_player()` 確實降低的數值；即使狗自己承受傷害也不會計到玩家。箭經 `EnemyProjectile` 的真飛行線段碰到舉盾範圍才算攔截。反擊使用 `companion_counter_resolved("used")` 的現有命中點；騎士須命中敵人，遠程須是普通投射物實際命中。蓄力消失另記 expired / cancelled。

### 重跑

先用 `godot --headless --editor --path . --import` 匯入。測 #33 時，用獨立 checkout，僅複製本次的 `tests/integration/first_shield_probe.gd` 與 `.tscn`。每次指定新的輸出目錄，含原始 JSON、程序 log 和總表。例如：

```sh
python tools/first_shield_trials.py --root /path/to/imported/game --out /tmp/shield-new-run --borrow off on --response skip call follow --workers 1
```

基準 #33 使用 `--borrow off`。原生 Linux 實景可在 X11 下使用 `godot --rendering-method gl_compatibility --resolution 360x640 --fixed-fps 60 --disable-render-loop res://tests/integration/first_shield_probe.tscn -- --speed=1 --policy=escape --build=route --guard=off --seed=7 --class=knight --borrow=on --response=call --report=/tmp/first-shield.json --shield-shots=/tmp/first-shield-frames`。只有在捕捉事件時要求實際 framebuffer 重繪；此工具沒有測量裝置幀時間。
