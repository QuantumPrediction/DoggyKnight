# 弓手 1-4 無提示試玩

供主持人使用。在「稻草人包圍網」觀察玩家怎樣察覺攻擊、何時叫同伴，以及獲得反擊蓄力後是否繼續走位或停步出手。這是首章中段的可讀性觀察。從標題自行學會操作，需要另一批初次玩新遊戲的觀察。

## 開場

在有 Godot 4.7.2 的桌面，於專案根目錄操作。新取出的原始碼先執行一次 `godot --headless --editor --import --path .`。預定 6–8 位不同參加者，按到場次序交替分派神射、遊騎，首位神射。每人首輪只開一條路線、重新啟動一次場景。同人重試或後來自願換路另記。

| 首輪分派 | 啟動指令 | 正式存檔的入場狀態 |
| --- | --- | --- |
| 神射 | `godot --path . res://tests/integration/archer_1_4_trial.tscn` | 六級、97 活力，有嗅嗅、握手及尋回把戲 |
| 遊騎 | `godot --path . res://tests/integration/archer_1_4_outrider_trial.tscn` | 六級、89 活力，有打滾、暴衝及搖尾巴把戲 |

兩條路線都從正常的 1-4 開場對白進入，配備土屬普通一級弓與護甲，同伴同行，護陣教學尚未完成。玩家自行推進對白，接手後使用正常戰鬥、預警、失敗及重試流程。每次啟動均建立獨立臨時存檔及遊玩紀錄，正常退出會清除。

只向參加者說：「請試著帶弓手通過這一關。你可以重試、暫停，隨時結束也可以。」讓玩家自行閱讀遊戲內已有的提示。留約五分鐘，若玩家想重試，記下是主動還是受邀。第一輪保留參加者自己選擇的對白節奏、走位、裝置及輸入方式。

## 觀察與訪談

每次記下匿名場次編號、版本、平台、輸入方式及是否玩過相似遊戲。記下首次事件及時間，以及玩家有否自行略過或重開遊戲內教學。有出現／未出現／觀察者無法判斷，分開填寫。看見玩家移動只證明有移動，是否理解提示須聽玩家自己的解釋。

| 時刻 | 同時記下甚麼 |
| --- | --- |
| 第一個明顯威脅 | 玩家站位、當時可見的追蹤／鎖定／重疊提示、玩家的下一個動作 |
| 攻擊鎖定到落點 | 玩家移出、留在原地或翻滾，是否有看得見的出路，當時還有甚麼吸引注意 |
| 第一次叫同伴及第一次取得反擊蓄力 | 分別記下呼喚、進圈／離圈、取得蓄力的時刻。獲得後第一個動作是繼續移動、轉向、停步、翻滾或其他？普通攻擊用出／蓄力過期／未能判定？按 Q 或點盾牌僅算呼喚 |
| 結束或失敗 | 到達哪一波、結束原因、主動重試與否、玩家原話。保留中途結束、完全沒叫同伴或從未取得蓄力的場次 |

第一輪之後再問：「剛才有哪一刻讓你改變打算？」「如果再玩一次，哪裡會採取不同做法？為甚麼？」只在玩家自行提到某個符號或聲音後，追問他當時怎樣理解。最後可以詢問想繼續或停下的原因。兩次以上出現同一個誤解時，保留具體時刻，以便下一次只更動一項設計來比較。

主持人備註。相同條件下的兩條謹慎弓手路線，共 101 次受擊中有 91 次來自普通稻草人揮擊。留意玩家怎樣察覺扇形起手、當時的撤離方向及重新站定的選擇；這項資訊留待觀察者使用。 [實際受擊紀錄](archer-1-4-hits.csv)

兩個版本都從**實際用出護陣普通反擊**起算。原卡約 2.2 秒遊戲時間內遇到附近仍有效的攻擊預警，記為一次接觸機會。另記預警或撤離路徑有否落入舊卡位置，以及當時第一個可觀察動作。用「有／無／不確定」分欄填寫；附近警示被遮住、無法辨認時間或無法判斷是否消耗蓄力時，留作不確定。成功卡有否彈出是另外一項結果。4.4 秒的補出期限不延長接觸窗口。[原卡的比較條件](../guard-success-toast/README.md)

每條路線分別列首輪總人數、曾取得蓄力人數、確認接觸人數、未接觸及不確定人數。實際接觸到原卡遮擋的子組還要核對舊卡區相交。只有同一路線、同一份起點存檔才可比較版本，預先平衡版本次序。首輪停下或重試不換人補額；沒有確認接觸便不能判定呈現效果。主持人不展示重播、不提示護陣或翻滾，也不要求重現指定警示。

## 場景來源與核對

兩份 v11 存檔均來自乾淨測試帳戶走完 1-1 至 1-3 後，由正式流程寫入的首個 1-4 檢查點。來源同為第一章、種子 19、cautious 走位、reactive 護陣及 common1/earth 配裝。遊騎保留自己的活力、經驗、把戲、零食及隨機狀態。玩家接手後按正常遊戲演進，不保證遇到神射 `20980.1` 或遊騎 `17197.2` 的封存時刻。
