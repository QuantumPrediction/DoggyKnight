# 弓手 1-4 無提示試玩

供主持人使用。這一輪想知道，玩家何時看懂「稻草人包圍網」裡的攻擊預警，受到威脅時能否自行選擇下一步。先收集 6–8 人的經歷，保留失敗和中途結束的場次。這是首章中段的可讀性觀察。新手從標題自行學會操作，需另從新遊戲觀察。

## 開場

在有 Godot 4.7.2 的桌面，於專案根目錄執行以下指令。新取出的原始碼先執行一次 `godot --headless --editor --import --path .`。每位玩家重新啟動一次試玩場景。

```sh
godot --path . res://tests/integration/archer_1_4_trial.tscn
```

玩家會看到 1-4 的正常開場對白，接著接手六級神射弓手、土屬普通一級弓與護甲及同伴。使用正常戰鬥、裝備、預警、對白、失敗及重試流程。每次啟動均建立獨立臨時存檔及遊玩紀錄，正常退出會清除，玩家原有的進度及設定保存在原處。

只向參加者說：「請試著帶弓手通過這一關。你可以重試、暫停，隨時結束也可以。」讓玩家自行閱讀遊戲內已有的提示。留約五分鐘，若玩家想重試，記下是主動還是受邀。第一輪保留參加者自己選擇的對白節奏、走位、裝置及輸入方式。

## 觀察與訪談

每次記下匿名場次編號、版本、平台、輸入方式及是否玩過相似遊戲。記下首次事件及時間。有出現／未出現／觀察者無法判斷，分開填寫。看見玩家移動只證明有移動，是否理解提示須聽玩家自己的解釋。

| 時刻 | 同時記下甚麼 |
| --- | --- |
| 第一個明顯威脅 | 玩家站位、當時可見的追蹤／鎖定／重疊提示、玩家的下一個動作 |
| 攻擊鎖定到落點 | 玩家移出、留在原地或翻滾，是否有看得見的出路，當時還有甚麼吸引注意 |
| 離開危險後 | 第一次重新站定、出手或使用護陣的時機。遇到意外受擊則記下玩家原本在做甚麼 |
| 結束或失敗 | 到達哪一波、結束原因、主動重試與否、玩家原話。場景未出現的提示留空 |

第一輪之後再問：「剛才有哪一刻讓你改變打算？」「如果再玩一次，哪裡會採取不同做法？為甚麼？」只在玩家自行提到某個符號或聲音後，追問他當時怎樣理解。最後可以詢問想繼續或停下的原因。兩次以上出現同一個誤解時，保留具體時刻，以便下一次只更動一項設計來比較。

主持人備註。相同條件下的兩條謹慎弓手路線，共 101 次受擊中有 91 次來自普通稻草人揮擊。留意玩家怎樣察覺扇形起手、當時的撤離方向及重新站定的選擇；這項資訊留待觀察者使用。 [實際受擊紀錄](archer-1-4-hits.csv)

## 場景來源與核對

試玩檔是在乾淨測試帳戶從頭實際打完 1-1 至 1-3 後，擷取的第一個 1-4 可續玩 v11 存檔。來源為第一章、神射路線、種子 19、cautious 走位、reactive 護陣及 common1/earth 的工程對照。該次完整工程報告與 PR #17 相同。試玩讀取原有的關卡、裝備及隨機狀態，角色由玩家操作。敵人的個別決策和輸入隨正常遊戲進行，每位玩家的戰鬥可能不同。
