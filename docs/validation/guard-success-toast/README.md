## 正式流程／控制測試

- 先出成功卡再來預警、先有預警再成功、無衝突（包含遠處、已隱藏與純登場標記）三者分開檢查；仍在教學中的提示保留。附近預警第一幀不重新排版，顯示中的警示不改。
- 用送入正式搖桿的合成觸控事件驗證逾期或離開危險時不改既有按鈕位置、不斷開正在拖動的手指。成功卡收起後，不留自己的隱形關閉鈕阻擋新觸控。暫停不推進期限，倒下與重新打開時清空上次狀態。
- 確認只發一次原有完成事件及寫檔，延後畫面不延後寫檔；已離開的角色不回答新 HUD。維持原有 EventBus 合約並只加兩個查詢／回傳信號。

護陣與流程 21 項、預警 8 項、事件合約 2 項及完整 936 項均通過，退出 0。完整回歸在另一份同樣的程式和測試來源上執行；退出時仍有 33 個物件、24 個資源與 RID 警告。[回歸與來源指紋](suite.json)

## 真人觀察與界限

不能把候選「有沒有畫出成功卡」拿來篩選有機會受影響的場次。原版有一次有效反擊成功、原本約 2.2 秒呈現窗口期間有附近預警，且警示或退路落入原版佔用區域，才算一次候選前的接觸機會；單看路線或角色已踩進扇形不算。4.4 秒是候選逾期上限，不是用來擴大兩版接觸分母。原有 [5 分鐘無提示試玩](../scene-lifetime/archer-trial.md) 的神射路線仍可完成護陣，但沒保證採到遊騎案例；可記「碰到／沒碰到／不確定」、下一個動作和嘗試結束後的原因，保留所有場次並另列實際接觸分母。不為重演而提示或教操作。本輪沒有真人、Windows／手機／手把、音效、長局或引擎崩潰修復證明，沒有重新評為 9/10。
