# 金毛騎士：繪本美術重製 v0.2.0-art

2026-11-18。以 `codex/windows-playtest`（6c6032a）為基礎，依擁有人「完整重新設計並放進遊戲」的要求製作。工作分支為 `codex/storybook-art-overhaul`。

## 視覺方向

暖色中世紀繪本：金毛的蜜金毛色、皇家藍披風、舊黃銅盔甲，搭配森林綠、湖水藍與羊皮紙。角色外輪廓清楚，場景邊緣細緻，中央留給戰鬥、預警和走位。狗狗失敗仍以休息表現。

金毛、柴犬蘭斯洛特、柯基崔斯坦、鬥牛犬貝德維爾、聖伯納高文、西施犬梅林、薩摩耶湖中仙女、紅狐摩根娜與杜賓莫德雷德維持各自辨識度。摩根娜正式揭曉前的對白圖使用暗色剪影。

## 與玩法的連接方式

`ArtDirector` 在既有場景出現時裝上繪製層。原 SpriteFrames、動畫時長、animation_finished、碰撞尺寸、關卡資料、傷害和存檔格式保留；新圖依原角色大小及腳底高度繪製。因此本輪不是新的投劍回收玩法，也沒有藉美術更動重調敵人數值。

畫面改用 `canvas_items`，使高解析度插畫和字型以視窗解析度繪出；遊戲邏輯仍為 180×320 單位。像素素材保留為動畫／資料來源，新插畫使用 linear filter。小遊戲的動態卷軸、節拍圈、魚和部分裝飾仍以程式繪製；這些不是逐幀手繪影片。

生成圖集不保證等寬空白邊緣；阿瓦隆頭目圖集採個別列界線，避免相鄰角色羽飾露出。底板必須放在其既有文字子節點之前；空白佈局 StyleBox 不加邊框，避免 ScrollContainer 撐大。

## 素材與字型來源

- 新插畫使用 OpenAI `image_gen` 生成；有針對犬種、弓兵武器、摩根娜造型、透明背景的修正。完整請求保存在 `ART_PROMPTS.json`。
- PNG 原稿直接加入 `assets/illustrated/`，遊戲透過 AtlasTexture 取區域；沒有用 Python 合成或重畫生成圖片。
- `StorySans.otf`、`StorySerif.otf` 為 Noto Sans/Serif CJK TC 子集，附 `Noto_CJK_LICENSE.txt`，遊戲製作名單內亦有授權內容。原 Cubic 11 及其授權保留。
- 舊像素素材、音效、音樂的來源紀錄見 `licenses.md`。音樂音效未重製。

## 試玩

Windows x64：雙擊 `DoggyKnight_Storybook_Windows.exe`。WASD／方向鍵移動，停下自動攻擊，Space 必殺，Esc 暫停；其他選項以滑鼠操作。主畫面左上「美術巡覽」可一次看完各章畫面。

這是整合在原遊戲內的繪本試玩版。它仍是直向遊戲；本輪沒有完成橫向 Steam 版、完整手把操作或商店發佈。角色採有限姿勢動畫，還不是逐格精修的完整動畫製作。

## 驗證與界線

完整回歸與新增的六項整合測試涵蓋：36 個正式關卡均安裝新背景、全部 30 個角色有新圖、攻擊結束事件、左右朝向、全部劇情頁／把戲圖示、美術巡覽不改進度及安全區，以及技能標記不遮住說明。

`tools/capture_illustrated.gd` 以真實 Godot renderer 擷取主畫面、六章戰鬥、營地、訓練、劇情、技能、巡覽、六章頭目及三種小遊戲。它用測試場景配置和無敵主角方便檢查畫面，不代表真人完成關卡或難度驗收。

建置使用指定 Godot 4.7.2，並從輸出的 Windows EXE 內部資料包重新載入 36 關、四位同伴及全部 28 個新 PNG；另外從該資料包的正式流程啟動主畫面、開始新遊戲、略過開場對白、進入第一關並取得實際渲染截圖。實際測試結果見 `status/LINE_INT.md`。

目前的圖形驗證來自 Linux／Mesa 軟體 OpenGL；尚未完成 Windows 實機人工試玩或手機效能檢查。既有測試結束時仍有資源未釋放警告，不能稱為完全沒有警告。Windows 執行檔仍未簽章。
