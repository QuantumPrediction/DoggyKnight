# Golden Knight 0.8.0：看懂護陣，打出反擊

本版接續完整 0.7.0。保留三職業、六章、永久裝備、四元素刻印與共鳴；這次集中改善首章戰鬥的理解與操作回饋，沒有調高角色傷害、降低敵人血量或改掉原有冷卻。

## 玩家看得到的變化

- 護陣展開後，按鈕會明確顯示「受保護」或「圈外」，以實際保護半徑判斷。只是同伴開始跑過來，不算已受保護。
- 取得蓄力後，顯示真正的加成與剩餘時間。它與戰鬥使用同一個時鐘；暫停不會偷走時間，也不會自行跑出假的 UI 倒數。
- 在 1-3 或 1-4 首次遇到同伴合作時，底部會出現可略過的小提示。依實際情況解釋走位、同伴就位、圈內外、停步、射程與攻擊恢復。
- 隊長出招時，提示優先提醒躲避。蓄力可以由同伴擋彈取得，不要求玩家故意挨打。
- 真正用在普通攻擊後才記錄提示完成。揮空、按下護陣、必殺技、蓄力過期或角色倒下都不算完成。多種裝備蓄力仍只取最高值。
- 可以按 × 略過本輪提示；暫停選單的「再看護陣提示」可重新打開。已完成的玩家不會每次重看。
- 三個新圖示由 GPT Image 為遊戲生成，實際整合到正式介面；截圖來自 Godot 渲染。

存檔升為 v10，舊 v9 的裝備等級、刻印、貨幣及關卡進度會保留。新完成旗標預設為未完成；故事仍以關卡安全點續玩，無盡試煉沒有中途續玩。

## 試玩本版

解壓 `Golden_Knight_0.8.0_Windows.zip`，執行其中的 `DoggyKnight.exe`。主畫面版本應顯示 0.8.0。無需安裝 Godot。

| 操作 | 方法 |
| --- | --- |
| 移動 | WASD／方向鍵，或滑鼠拖曳 |
| 普通攻擊 | 射程內有目標時放開移動，自動攻擊 |
| 護陣 | 有貝德維爾同行時按 Q，或點盾牌 |
| 必殺技 | 忠誠度滿後按 Space，或點必殺技按鈕 |
| 暫停、重看提示 | Esc／暫停按鈕 |

第一次試玩可以先選騎士。在 1-3 看同伴是否真的到位，在護陣邊界進出一次；觀察「圈外」是否足以提醒你失去減傷。取得反擊蓄力後，先避險，再停下攻擊。比較「照提示操作」與「只要冷卻好了就按 Q」哪個更容易理解、較少受傷。若不想看提示，可直接略過。

這是開發試玩版。Windows EXE 由匹配的官方 Godot 4.7.2 模板匯出，並在建置主機檢查內嵌遊戲內容；這不等於已在 Windows 實機、手機、手把或耳機上驗證。

## 距離 9/10 還缺甚麼

自動測試可以證明規則和流程，不能證明「好玩」或保證人氣。本版不根據新增功能數量調高評分。

1. **先驗證首章是否容易理解。** 下一輪讓未玩過的人自己開始，記錄首次看懂停步攻擊、護陣圈與反擊的時刻，以及錯誤理解的位置。目標是大部分玩家不用旁人解說便能完成這個循環；這是待驗證目標。
2. **釐清騎士 1-4 的壓力。** 同一機器人政策、相同種子與配裝的騎士結果與 0.7 相同；其中一個案例仍達倒下上限。先區分接敵距離、預警閱讀、同伴位置與操作政策，不靠全局降血量製造通關率。
3. **做出值得重玩的選擇。** 每職業兩條可辨認的構築路線、首章三種不同遭遇、同一開局經濟下的獎勵取捨，尚未在本版完成。以不同操作方式與風險回報為驗收，而非只增加百分比詞條。
4. **把可下載版本磨到可靠。** 原有資源清理警告、真實裝置效能、觸控與手把、配樂長時間聆聽仍須處理。收集玩家願不願意主動再開一局的理由後，才擴充更多內容或準備商店宣傳。
