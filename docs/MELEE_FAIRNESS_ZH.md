# 金毛騎士 0.8.1：近戰預警與首章公平性

2026-11-20（香港）。接續完整 0.8.0；這是可試玩的修正版本，尚未達到或證實 9/10。

## 這次玩家會感受到甚麼

- 普通／精英稻草人及隊長會在出手前標示實際衝刺落點的扇形；傷害判定使用同一個畫出的形狀。整個角色碰撞圈已離開紅色範圍，就不會被這次揮擊命中；身體仍壓住邊緣則可能中招。
- 已蓄力的士兵不再被附近敵人推得整塊預警滑走。走到完整扇形後方可躲避；不再存在未畫出的背後命中圈。
- 隊長現存援兵最多四隻。已經有三隻，就只預告、召出一隻；蓄力中空出更多位置也不會突然補上未預告的士兵。
- 受擊觸發裝備暈眩時，稻草人保留被打斷後的收招狀態。打斷或重複呼叫不會再次造成揮擊或召援。

玩家／敵人的傷害、生命、速度、出招時間、裝備價格及護陣數值未調整；存檔維持 v10。三職業、六章、裝備與四元素共鳴全部保留。

## 為甚麼先修這裡

舊版 seed 7 騎士兩次在 1-4 失敗的 291 點受擊，209 來自稻草人揮擊、72 來自飛行物、10 來自烏鴉俯衝；沒有隊長橫掃命中。追蹤器的整份普通試玩結果與未加追蹤時完全相同。

因此不能把失敗全部歸咎於頭目，也不能靠增加全局血量宣稱已解決。本輪先修正可重現的預警／判定差異及援兵超額，並把普通稻草人包括在內。
