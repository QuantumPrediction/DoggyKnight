# B 線(關卡流程與成長)狀態報告

最後更新:2026-11-15(M1 完成)

## 已完成

- **B1 遊戲流程**:標題 → 關卡 →(升級選把戲)→ 過關結算 →(1-2、1-4 之後)營地 → 下一關;金毛睡著 → 失敗結算 → 「再試一次」(立即回到戰鬥,遠少於 2 秒)或回標題;打敗黑騎士 → 最後的結算 → 回標題。所有畫面切換都在 `game/flow/flow_main.gd`。
- **B2 波次**:一波一波出敵人;場上敵人全部倒下(連頭目召喚的小怪)才進下一波;最後一波清空就過關。同一組敵人會隔一點時間、從不同的出生點出來,不會在金毛身邊冒出來。
- **B3 六關資料**:`data/levels/level_1_1.tres` 至 `level_1_6.tres`,章節次序在 `data/levels/chapter_1.tres`。鬥牛犬從 1-3 開始加入;1-5 用精英稻草人兵;1-6 是黑騎士。
- **B4 經驗與升級**:第 2 級要 5 點,之後每級多 3 點。升級時遊戲暫停,出把戲三選一;一次升兩級就連續選兩次。
- **B5 把戲系統**:每次抽 3 個不同的把戲;數值類把戲(坐下、搖尾巴、尋回)直接改金毛的數值,可以重複選、效果疊加。
- **B6 六個把戲資料**:`data/tricks/` 內 6 個檔案,圖示用 `assets/icons/tricks/`。
- **B7 結算資料**:用時(暫停的時間不算)、擊倒數、這一關學會的把戲、等級等。
- **B8 營地銜接**:1-2、1-4 過關後進營地,營地的「繼續」之後進下一關。小遊戲給的「下一關加成」在下一關過關後歸零,失敗重試時保留。
- **B9 存檔**:只存三樣東西:到達的關卡、零食、音效開關。在每關開始、過關、切到背景、回標題時寫入。先寫暫存檔再改名,所以 App 在寫到一半被關掉,舊存檔也不會壞。關掉再開,標題會出現「繼續」。
- **B10 難度參數**:全部集中在 `game/progression/difficulty.tres`(升級所需經驗、把戲數目、波次之間等多久、過關後幾秒顯示結算、倒下後幾秒顯示失敗等)。
- **暫停與手機**:返回鍵(桌面按 Esc)在關卡中打開暫停選單,再按一次繼續;選把戲時返回鍵無效;在標題畫面,只有 Android 會問「要離開遊戲嗎?」。切到背景時立即存檔並打開暫停選單。
- **自動化測試**:`tests/line_b/` 共 67 個測試,包括「從新遊戲一路玩到打敗黑騎士」的完整流程測試。全部 104 個測試通過。

## 怎樣試玩

1. 用 Godot 打開專案,開啟 `tests/line_b/flow_sandbox.tscn`,按「執行目前場景」(F6)。或在終端機輸入 `godot --path . res://tests/line_b/flow_sandbox.tscn`。
2. 按「New Game」。按住畫面拖曳 → 金毛移動;放手 → 停下自動攻擊。敵人變紅是要揮擊了,走開就打不中。**點一下敵人,敵人立即倒下**(方便快速試完六關)。
3. 右上角「II」是暫停。左下角「DBG」打開測試工具:全部敵人倒下、加經驗、模擬切到背景、模擬返回鍵、讓金毛睡著、4 倍速、模擬瀏海、模擬 Android。
4. 正式主場景是 `game/flow/main.tscn`(整合時才設為開機場景)。別線的正式畫面合併後,它會自動改用正式畫面;沙盒則一直用替身,不受別線影響。
5. 現在看到的英文畫面和方塊人物都是替身,C 線的正式畫面與美術合併後就會換掉。

## 需要擁有人決定的事

- **打敗黑騎士之後**:現在是回到標題,「繼續」按鈕消失(要重新開始)。另一個做法是保留「繼續」讓玩家重打黑騎士。建議:維持現狀,第二章做好之後再決定。
- **「繼續」會重新開始一輪**:依計劃,存檔只記到達哪一關,所以「繼續」時等級和把戲會歸零,從那一關重新開始。如果試玩時覺得太嚴苛,可以改成連等級與把戲一起存。建議:先照計劃,M3 試玩後再決定。
- 以上兩點都已經照建議做好,不決定也可以照常試玩。

## 建議

- 關卡長度:用機器人(比真人有效率,而且永遠閃得開)跑替身戰鬥,每關約 47 至 62 秒;真人預計約 60 至 90 秒,符合目標。正式戰鬥合併後要再量一次。
- 每關約升 1 至 2 級,整章大約升到第 10 級。
- 營地之後如果 App 在下一關開始前被關掉,再開時會直接從下一關開始(略過營地)。原型可以接受;正式版可以考慮把「營地」也存起來。
