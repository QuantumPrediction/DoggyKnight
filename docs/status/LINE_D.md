# D 線(營地、小遊戲與手機建置)狀態報告

最後更新:2026-11-16(M3 打磨:DP1 至 DP6 全部完成)

## 怎樣試玩(不用寫程式)

1. 用 Godot 4.7.2 開啟專案,在左下角的「檔案系統」打開 `tests/line_d/camp_sandbox.tscn`,按右上角「執行目前場景」(或 F6)。
2. 按「進入營地」(第一次營地)或「第二次營地(有鬥牛犬)」。你會看到:
   - 星空會閃、偶爾有流星劃過、雲慢慢飄,遠處有亮著燈的卡美洛城堡;營火會跳動、冒火星和煙,火光一閃一閃地照在地上;螢火蟲在草地上飛。
   - 卸下盔甲的金毛趴在火旁呼吸、眨眼、搖尾巴;它的劍插在地上,胸甲放在旁邊。
   - **點一下金毛 = 摸摸頭**:金毛瞇眼吐舌、耳朵豎起、尾巴搖得飛快,頭上有一隻手在揉,冒出愛心;一顆愛心飛到「滿意度」條,條會閃一下並顯示「+2」。手機上會輕輕震一下。
   - 還沒摸過時,金毛頭上會冒出一個「愛心泡泡」,提示可以摸它(不需要文字)。
   - 第二次營地時,鬥牛犬坐在火旁的木頭上;點它會「汪!」。
3. 按「拉扯王室卷軸」:
   - 倒數是彈出來的大數字 3、2、1(每秒一聲),然後「拉!」。
   - 在下半部按住往下拖,卷軸被拉出來;拉得快時兩旁和紙上有速度線。
   - 墨水漬一到金毛嘴邊就**立刻停手**,會出現大大的「完美!」、閃光、加 5 公分,手機輕震;慢一點才停是「好!」;停住時還繼續滑會扣 1.5 秒,金毛臉上沾到墨水。
   - 15 秒後手機震一下,金毛被卷軸包成一捲,只露出頭,綁上紅色蝴蝶結。
   - 評價畫面從下面彈上來,星星一顆一顆亮起(每顆一聲、有閃光),長度由 0 數上去,寫出「完美停住 ×N」與獎勵。點一下回到營地,活力條與滿意度條會長上去並顯示「+N」。
4. 「繼續冒險」離開營地(畫面回到測試選單,主控台會印出所有訊號)。

整個遊戲裡:第 2 關、第 4 關過關後的營地就是這個畫面(從標題開始玩即可)。音效與音樂由 C 線同時製作,檔案還沒放進來時會安靜略過。

## 已完成(M3 打磨,DEV_PLAN 第 15 節)

- **DP1 營地氣氛**(`game/camp/`)
  - 新的營地專用金毛圖:卸下盔甲趴著的金毛(呼吸 2 格、眨眼、開心的瞇眼吐舌 2 格)與會搖的尾巴(3 格)。由 `game/camp/art/make_camp_art.py` 用程式畫出,顏色用 C 線的調色盤,風格與 C 線的角色一致。
  - 夜空(星星閃爍、十字大星、流星、慢慢飄的雲、月亮與月暈、遠山、亮燈的城堡剪影、松樹)、營火(石圈、木柴、炭火、三層火焰、火星與煙的粒子、閃爍的光暈照在地上和角色身上)、螢火蟲、草地上的小花、圓桌上的卷軸與蠟燭、卸下的劍與胸甲、木頭椅。
  - 摸摸頭:冒 `heart` 粒子、`pet` 音效、`Haptics.play(&"light")`;每摸一下滿意度 +2,**每次營地最多 5 下有加分**(之後金毛照樣開心,只是不加分);連點太快(0.3 秒內)不算。全部在 `game/camp/camp_config.tres`。
  - 鬥牛犬:`GameState.level_index >= 2`(即第二次營地)時坐在火旁(用 C 線的 `bulldog_frames.tres`)。點它會「汪!」(`bark` 音效、輕震)。
  - 營地自己播 `Music.play(&"camp")`。
  - 介面:大標題用 C 線主題的 LabelTitle;選單按鈕按下會壓扁、放開彈回;選單從下面滑入;「同伴」用藍色的次要按鈕樣式;進營地、開關小遊戲時畫面由黑淡入;小遊戲回來時條會閃一下、冒閃光與「+N」。
- **DP2 小遊戲手感**(`game/minigames/`)
  - 倒數:36 像素的大數字彈出來、每秒 `countdown` 音效、外圈顯示這一秒剩多少;開始時彈出「拉!」(`whoosh`)。
  - 拉卷軸:速度線(紙上與兩旁)、`scroll` 音效。
  - 「完美!」:墨水漬到達後 0.2 秒內停手、而且沒有犯錯 = 完美(`perfect` 音效、`sparkle` 閃光、`Haptics.play(&"light")`、+5 公分);慢一點是「好!」。數值在 `game/minigames/scroll/scroll_config.tres`(`perfect_window_sec`、`perfect_bonus_score`)。
  - 結束:`Haptics.play(&"medium")`,金毛被卷軸一圈圈纏住,最後包成一捲、綁上蝴蝶結,左右扭動、冒愛心。
  - 評價畫面:面板彈上來、星星逐顆亮起(`star` 音效、`star_burst` 閃光;拿滿 3 顆星時輕震)、分數由 0 數上去、文字在星星亮完後淡入;星星亮完之前不能點掉(`results_min_sec` 1.4 秒)。面板會避開被包起來的金毛。
  - 小遊戲的桌面:木板深淺交錯、接縫、木紋、蠟燭與暖光、四周稍暗。
  - **評分門檻重新調整**:由 80 / 160 / 240 改為 **70 / 150 / 230 公分**(`scroll_grading.tres`)。做法:用真正的小遊戲,逐格模擬三種玩家各 5 次(`tests/line_d/test_scroll_balance.gd`):隨便玩的 109 至 128 分(1 顆星)、普通玩家 168 至 179 分(2 顆星)、熟練玩家 257 至 263 分(3 顆星)。整合的自動試玩機器人約 200 分(2 顆星)。
- **DP3 震動權限**:「Android」「Android AAB」「Android Sandbox」三個匯出設定加了 `permissions/vibrate=true`。重新建置的 APK 用 `aapt2` 檢查:**唯一的權限是 `android.permission.VIBRATE`**。已更新 `store/` 的隱私權政策、資料安全、App 隱私說明與 `platform/README.md`(震動不讀取、不傳送任何資料,答案仍是「不收集資料」;iPhone 的震動不需要權限)。
- **DP4 效能**:`tests/line_d/stress_test.tscn` 一直保持 40 隻敵人(用正式的場地、主角、稻草人兵和烏鴉;被打倒就補回來),再加上比真實戰鬥更激烈的特效:每秒 10 次 `hit_burst`、打倒時 `straw_bits` / `feathers`、跑步的 `footstep_dust`、`sparkle`,以及定時的 `shockwave`、`level_up_pillar`、`ultimate_burst`、`confetti`、`star_burst`、`heart`。結果見下方「效能數字」。
- **DP5 商店截圖**:`store/screenshots/capture.gd` 已重新執行(三種尺寸各三張):營地摸摸頭(鬥牛犬、流星)、小遊戲「完美!」、三顆星評價。商店說明文字加入新賣點(配樂、頭目登場、連擊、三顆星、營地摸摸頭、完美停住),並寫了建議的截圖順序與每張的說明文字(`store/listing_zh-Hant.md`)。
- **DP6 測試**:新增 22 個(摸頭的上限與滿意度、每次營地重設、滿意度不超過 100、連點、金毛的反應、點擊範圍、小遊戲中與離開後不能摸、鬥牛犬出現的時機、愛心泡泡、營地音樂;完美停住的判定、太慢是「好」、犯錯兩者都不是、時限邊界、時間到震動、星星逐顆亮起、「拉!」;VIBRATE 是唯一的權限;三種玩家的評分)。D 線共 66 個測試,全部 277 個測試通過。

### 效能數字(DP4,雲端無畫面模式,40 隻敵人)

| 情況 | 每格 CPU(腳本 + 物理) | 說明 |
| --- | --- | --- |
| 沒有特效 | 平均 0.76 + 2.50 = 3.3 毫秒 | 一格的時間上限是 16.7 毫秒(60 FPS) |
| 有特效(有上限) | 平均 1.09 + 2.49 = 3.6 毫秒,最慢 1% 為 4.7 毫秒 | 同時最多 22 個特效、206 顆粒子 |
| 有特效(不設上限) | 平均 1.26 + 3.67 毫秒,最慢 1% 為 7.5 毫秒 | 最壞情況 |

特效本身每格只多約 0.35 毫秒;最重的是 40 隻敵人的物理。雲端沒有 GPU,畫圖的負擔要在手機上量(「Android Sandbox」→「壓力測試」)。

**建議每種特效同時存在的上限**(以 C 線現在的粒子數計算;C 線加大粒子數時要相應調低):`hit_burst` 8、`straw_bits` 6、`feathers` 6、`footstep_dust` 4、`sparkle` 6、`heart` 4、`star_burst` 3、`shockwave` 2、`level_up_pillar` 1、`ultimate_burst` 1、`confetti` 1;畫面上的粒子總數最好不超過約 250 顆。

## 被甚麼卡住

- 沒有。雲端沒有手機,所以手感、震動強弱、真實效能都還沒在實機上試過。
- **給其他線與整合工作階段**:
  - B 線:營地自己播 `camp` 音樂;離開營地後由 B 線播下一關的音樂。營地依賴「營地顯示時 `GameState.level_index` = 剛打完那一關的索引」(第二次營地 = 3)來決定鬥牛犬是否出現。
  - C 線:營地與小遊戲用到這些音效 id:`pet`、`bark`、`perfect`、`countdown`、`whoosh`、`star`、`scroll`、`ink`、`clear`、`ui_tap`;粒子:`heart`、`sparkle`、`star_burst`。檔案放進來就會自動有聲音與新特效。C 線的 `goldie_frames` 不再用在營地(營地有自己的金毛圖),小遊戲仍然用 C 線的 `idle`。
  - A、C 線:上面的特效上限建議。
  - 整合:`i18n/strings.csv` 新增 `CAMP_BULLDOG_BARK`、`CAMP_SANDBOX_CAMP2`、`MINIGAME_GO`、`MINIGAME_PERFECT`、`MINIGAME_GOOD`、`MINIGAME_PERFECT_COUNT`(放在 D 線原有的那一段,減少合併衝突)。

## 需要擁有人決定的事(我先替你決定了,想改只要改資料檔)

1. **摸頭的獎勵**:每摸一下滿意度 +2,每次營地最多 5 下(+10)。想更多或更少:改 `game/camp/camp_config.tres` 的 `pet_satisfaction_gain`、`pet_rewards_per_visit`。
2. **小遊戲門檻**:70 / 150 / 230 公分(以模擬玩家估計)。實機試玩後覺得太難或太易,改 `game/minigames/scroll/scroll_grading.tres`。
3. **「完美!」的時限**:墨水漬到達後 0.2 秒內停手。太難就加大 `scroll_config.tres` 的 `perfect_window_sec`(例如 0.3)。
4. **營地的金毛是 D 線自己畫的**(卸下盔甲、趴著;C 線原本的睡覺圖頭上有「Zzz」,不適合被摸時醒來開心的樣子)。C 線日後想重畫,只要換 `game/camp/art/` 的圖或改 `camp_config.tres` 的 `goldie_frames`。
5. 以前的決定仍然有效:套件識別碼 `com.doggyknight.prototype` 是佔位(第一次上傳商店前一定要決定,之後不能改);每次營地只能玩一次小遊戲(`minigame_plays_per_visit`);切到背景回來後要點一下才繼續(`resume_on_foreground`)。
