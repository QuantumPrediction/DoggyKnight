# 進度報告

每條線一個檔案:`LINE_A.md`、`LINE_B.md`、`LINE_C.md`、`LINE_D.md`。只改自己那一個。

每次收工更新,格式固定(DEV_PLAN 第 5 節規則 7):

| 欄位 | 寫甚麼 |
| --- | --- |
| 已完成 | 任務編號與一句話,例如「A1 虛擬搖桿:完成,可在 combat_sandbox 試」 |
| 進行中 | 正在做的任務與做到哪裡 |
| 被甚麼卡住 | 等別線的東西、合約不足、環境問題。發現別線的錯誤也寫在這裡,不要動手修 |
| 下一步 | 下次開工第一件要做的事 |
| 需要擁有人決定的事 | 用淺白的中文寫清楚選項與你的建議 |
| 建議 | 超出範圍的好主意,只記錄、不實作 |

擁有人不會寫程式:寫給擁有人看的部分不要用術語,要說明怎樣試玩。
