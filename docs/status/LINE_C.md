## 被甚麼卡住

- 沒有卡住。給其他線的接線說明(不需要改程式,只是讓大家知道):
  - A 線:角色動畫名稱與路徑沒變。`attack`、`hurt`、`slam`、`down` 只播一次(可等 `animation_finished`),其他動畫循環。特效 `slash` 是 32×32、弧光朝右,請依目標方向旋轉;`ultimate_slash` 是 64×64 的置中光環。必殺技按鈕與暫停按鈕都在 `ui_touch_blocker` 群組;HUD、暫停選單、把戲選擇的根節點都不攔觸控(暫停選單與把戲選擇只有打開時才擋住點擊,此時遊戲已暫停),所以搖桿在其他地方都能出現。`ultimate_slash` 置中,可放大到半徑約 80 像素使用。
  - B 線:結算畫面與失敗畫面會自己播放 `clear` / `fail` 音效,B 線不必再播。`setup()` 在加入場景之前或之後呼叫都可以。HUD 判斷頭目關的方法:關卡 id 結尾是 `1-6`(或收到 `boss_phase_changed`);關卡開始時若有翻譯鍵 `LEVEL_` + id(把 `-` 換成 `_`,例如 `1-2` → `LEVEL_1_2`)就先顯示關卡名稱。
  - D 線:匯出設定可直接用 `assets/app_icon/` 的圖示;營地畫面可以用 `ui/theme/main_theme.tres` 的字型與按鈕。
  - 整合:已提出申請 `docs/requests/20261115-C-splash-and-theme.md`(設定啟動畫面、把介面主題設為全域預設)。
