# 整合報告(M2 與 M3 打磨)

更新:2026-11-16,整合工作階段。下半部是 2026-11-15 的 M2 報告,保留作紀錄。

## M3 打磨(v2.2):這一輪做了甚麼

擁有人要求「遊玩性高、觀賞性更高級、遊戲體驗達致頂級」。四條線依 DEV_PLAN 第 15 節同時打磨,已全部合併。

- **戰鬥手感(A 線)**:
  - 畫面震動、跳出來的傷害數字(握手的雙倍傷害用大字)、敵人被打中會擠壓變形、稻草和羽毛飛散。
  - 金毛跑步會揚塵、身體前傾,揮劍上下交替並有拖尾。
  - 連擊系統:2 秒內連續打倒敵人;5、10、20 連擊加忠誠度。
  - 預警圈會脈動,快打中時閃白;敵人從地面冒出;稻草人會分散包圍,烏鴉會兩隻接連俯衝。
  - 黑騎士:從城門走進來、第二階段怒吼並發紅光、被打倒時慢動作和白光,盔甲散落、頭盔滾走。
  - 必殺技:畫面變暗、光柱、金毛舉劍、所有敵人停頓、金色光環爆開。
  - 鬥牛犬舉盾時冒「汪!」,過關時和金毛一起歡呼。
  - 修正「單獨一隻稻草人兵打不中金毛」。
- **節奏與成長(B 線)**:
  - 每關開場有標題卡,換畫面有轉場,第一關有操作提示。
  - 三星評分(過關、時限內過關、受傷不多),保存每關最佳星數。
  - 每關有自己的出場隊形與高潮(包圍、一排、四角),最後一波最大,之前有喘息。
  - 音樂依情況切換;存檔加入音樂、震動、教學紀錄與最佳星數,舊存檔照樣可讀;結算後關掉 App 不會再略過營地。
- **美術、介面、音樂(C 線)**:
  - 全部角色加格數(眨眼、呼吸、搖尾巴、歡呼)。
  - 六個背景各有時段氣氛,並有會動的元素:早晨光線、麥浪、花瓣、風車、螢火蟲、暴風雨與閃電。
  - 全新粒子特效。
  - HUD:血條殘影、低活力心跳、連擊數、頭目血條、關卡標題卡、過關彩帶、必殺技切入畫面。
  - 其他畫面:會動的標題、星星逐顆亮起的結算、狗掌印轉場、暫停畫面的音樂與震動開關。
  - 七首原創 8-bit 音樂與一套更有層次的音效(全部約 1.3 MB)。
- **營地、小遊戲、手機(D 線)**:
  - 營地:營火粒子與光、流星、螢火蟲;**點金毛可以摸摸頭**;第二次營地鬥牛犬坐在營火旁。
  - 小遊戲:倒數、「完美!」停住獎勵、結束時金毛被卷軸包成禮物、星星逐顆亮起。
  - Android 版加入震動權限(唯一的權限)。
  - 壓力測試:40 隻敵人加特效,仍在預算內。
- **整合時修正**:
  - 關卡標題太長超出畫面:關卡編號移到小字那一行,並加測試確保六關的名稱都在畫面內。
  - 一行中文字串因半形逗號被截斷:已修正,並加測試確保每行只有兩欄。
  - 同時執行的測試共用同一個存檔資料夾,會互相覆蓋:改為每次測試用自己的資料夾,也不會碰到真正玩家的存檔。
  - 1-6 的★2 時限改為 55 秒,配合較長的頭目戰。

### 還沒驗證、要在手機上判斷的

- 震動強弱、畫面震動幅度、必殺技畫面變暗的程度、傷害數字大小:都在 `data/player/feel_tuning.tres`,可以直接調。
- 音樂與音效只做過程式分析(音量、循環接縫),還沒有人聽過。
- 「完美!」停住的判定時間 0.2 秒是否太嚴。
- 中階手機在特效最多時的實際 FPS(這裡沒有 GPU)。

## 一句話

四條線已接成完整的遊戲:**標題 → 六關 → 兩次營地(含小遊戲)→ 打敗黑騎士 → 第一章完**。桌面上可以從頭玩到尾,Android 除錯版 APK 已建好。還沒有在真的手機上試過。

## 怎樣在電腦上玩

1. 下載 Godot 4.7.2(一般版,不是 .NET 版):https://godotengine.org/download/archive/4.7.2-stable/
2. 在 GitHub 下載這個 repo(Code → Download ZIP)並解壓。
3. 打開 Godot → Import → 選 `project.godot` → 按右上角 ▶。
4. 操作:用滑鼠按住任何地方拖曳 = 移動;放手 = 停下並自動揮劍。右下角的劍形按鈕(忠誠度滿時出現)= 王者之劍。右上角 ‖ 或 Esc = 暫停(Esc 等同 Android 返回鍵)。

## 怎樣在 Android 手機上玩

除錯版 APK:建置後在 `export/build/doggyknight-debug.apk`(60 MB)。把檔案傳到手機,點開安裝(第一次要允許「安裝不明來源的應用程式」)。詳細步驟見 `export/README.md`。重新建置:`tools/install_android_tooling.sh` 一次,之後 `export/build_android.sh debug`。

## 整合時做了甚麼

- 依 A → B → C → D 合併四條線(實際次序 D、A、C、B,沒有互相覆蓋)。合併衝突只有 `i18n/strings.csv` 與 `docs/licenses.md` 兩個共用檔,兩邊都保留。
- 套用了全部合約變更申請(`docs/requests/`):
  - D 線:視窗縮小時重新適配畫面(core 的錯誤,已加測試);鎖 60 FPS、iPhone 靜音鍵、隱藏狀態列;註冊遊玩記錄 `PlayLog`。
  - C 線:啟動畫面、全域像素字主題。
- 主場景改為 `game/flow/main.tscn`(B 線的正式流程)。
- 新增 `tests/integration/`:一個整合測試(1-1 → 1-2 → 營地 → 1-3 鬥牛犬加入、存檔)與上面的試玩機器人。
- 接縫修正:A 線一個測試讀了佔位背景的內部屬性(C 線換圖後失效);D 線檢查 16 KB 的腳本在沒有 AAB 時誤報;兩個測試寫死了關卡或頭目數值。
- 難度第一輪(依試玩機器人):1-1 由 21 隻減為 16 隻(原本 102 秒);黑騎士生命 450 → 700(450 時 22 秒就打完,900 時太難)。
- 正式商店用的匯出設定不再打包任何測試場景;C 線的圖示已接到 Android 與 iOS 匯出設定。

測試:249 個自動化測試全部通過(`tools/run_tests.sh`)。
