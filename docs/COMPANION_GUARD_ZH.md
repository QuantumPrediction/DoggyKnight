# Golden Knight 0.7.0：護陣、反擊與首章戰鬥閱讀

2026-11-20（香港）。接續完整 0.6.0 四元素版本。本輪把「金毛與同伴互相保護」做成可主動使用的戰鬥選擇，並讓首章隊長的出招與收招更容易分辨。這是開發版本，尚未達到全遊戲 9/10 的驗收要求。

## 現在怎樣玩

貝德維爾在場時，按 **Q**，或點右下方的新盾牌按鈕。他會跑到金毛前方，守住一個固定位置。青綠圈是實際保護範圍，外圈弧線顯示剩餘時間；離開圈仍然可以移動和戰鬥，但不再享有這次保護。

| 規則 | 目前設定 |
| --- | --- |
| 護陣持續 | 抵達後 2.8 秒 |
| 冷卻 | 按下後開始計 10 秒 |
| 保護範圍 | 以同伴為中心，半徑 32 遊戲單位 |
| 圈內減傷 | 既有裝備減傷之後再乘 0.65，四捨五入，最少仍扣 1 活力 |
| 成功防守回饋 | 第一次實際減傷，或同伴實際攔住投射物且金毛在圈內，給一次反擊蓄力 |
| 反擊 | 3 秒內下一次普通攻擊命中 +25%；與現有元素／套裝蓄力只取較高值，不相乘 |
| 取消 | 同伴暈眩、金毛倒下、關卡完成或時間結束；不退還冷卻 |
| 失敗接近 | 同伴最多跑 1.2 秒；沒抵達也會花掉這次呼喚，不會瞬移 |

三職業都能呼喚；必殺不吃反擊加成，也不消耗這次蓄力。遠攻蓄力沿用現有投射物命中時結算，並非重新強化整串箭矢。後續受擊不會在同一次護陣內重複發放或延長反擊。

典型用法是先看隊長的紅色攻擊區、向側面避開，再在可站定攻擊的位置呼喚同伴。護陣不是無敵區；其他敵人、返回中的乾草叉和圈外危險仍需避開。若玩家一直移動離圈，或把正在擋敵的同伴調走，這次呼喚也可能沒有幫助。

## 這輪另外改了甚麼

- 騎士只有在敵人身體已進入實際武器射程時才起手，避免敵人尚在遠處便把攻擊冷卻花在空處。移動取消、敵人走開造成的真實揮空、攻擊力與射程保持原規則。
- 稻草人隊長會顯示橫掃、乾草叉、回飛、召援與蓄勢提示。收招時顯示實際剩餘空檔，提醒靠近、停步反擊。提示讀取真實狀態，不延長空檔，也不表示所有敵人都暫停攻擊。
- 新盾牌由 GPT Image 為本遊戲生成，已用在正式按鈕與戰場標記。可按、趕路、保護中、冷卻和暈眩有各自文字；保護中的圖示保持可見。
- 暫停畫面加入操作提示。三職業、原有裝備地水火風、同元素共鳴與存檔 v9 繼續保留；本輪不需要新存檔遷移。

## 測試結果說明了甚麼

同一開局：250 金幣，正式購買共 240 的 Lv.1 武器／護甲，沒有永久訓練；第一章、正常受傷、最多倒下三次、固定 60 Hz。騎士測地／火兩種配裝、種子 7／19／41，每種操控六組。

| 程式／操控 | 使用護陣 | 完成首章 | 合計倒下 |
| --- | --- | ---: | ---: |
| 0.6.0／原有走位 | 否 | 4/6 | 8 |
| 0.7.0／原有走位 | 否 | 4/6 | 8 |
| 0.7.0／看到危險便呼喚 | 是 | 4/6 | 10 |
| 0.6.0／依實際紅區閃避、進入真實射程停步 | 否 | 6/6 | 1 |
| 0.7.0／相同改良走位 | 否 | 6/6 | 1 |
| 0.7.0／改良走位＋看到危險便呼喚 | 是 | 6/6 | 2 |

**改良走位在舊版也有效，所以不能把通關改善歸功於新版護陣或近戰修正。** 無護陣時兩版本的通關、倒下和總受傷量相同。原有走位在近戰敵人附近退得過遠，錯失可以反擊的時機；這是測試工具本身的影響。

護陣在兩種騎士走位中分別實際減少 124／151 活力損失，但整場受傷反而增加、倒下也更多，顯示呼喚會改變同伴位置與戰局。它現在是一個有條件的手動工具，不能稱為已驗證的難度修復。法師／弓手各四元素、種子 7、使用護陣的八組均完成，零倒下；這只是功能通路檢查，不能當職業平衡證明。

原始結果、失敗、來源雜湊與真實引擎截圖見 [本輪驗證](validation/0.7.0/README.md)。截圖使用正式遊戲物件，但為固定位置的展示場景；不能當成真人自然通關紀錄。沒有 Windows／手機實機幀率或真人聆聽結果，也沒有新版 EXE。

## 下一輪最值得做的事

1. 在首章實際教一次「避開紅區 → 呼喚 → 站定反擊」，觀察陌生玩家能否理解圈內／圈外與冷卻。先驗證這個合作循環，再加其他同伴主動技。
2. 把每職業兩條會改變站位的構築及首章三種遭遇做成可比較的試玩內容；保留相同經濟起點，避免用後期史詩掩蓋早期問題。
3. 收斂已有清理警告，再安排最新可玩版本的實機、手把、觸控和聲音評審。新增功能數與自動測試數不會自動提高品質分數。

原有逐項評分仍是歷史設計判斷，這輪沒有用功能數量重新報一個更高分。達到 9/10 仍需要完整首章、真人理解度、長局穩定性及目標裝置的證據。
