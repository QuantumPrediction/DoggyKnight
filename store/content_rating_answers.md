# 內容分級問卷:建議答案

狀態:草稿,依 2026-11 的原型內容。分級結果由問卷自動產生,下面的「預期結果」只是估計。
送審前由上架工作階段按當時的問卷題目核對(兩家的問卷都會改版;Apple 在 2025 年改了年齡分級制度)。

## 遊戲內容摘要(填問卷時的依據)

- 卡通像素風格的奇幻打鬥:黃金騎士揮劍打倒**稻草人**、**烏鴉**與**空的魔法盔甲**(黑騎士)。
- v2.3 新增(仍是同一類內容):稻草人弓兵射出的卡通箭(有紅色預警線、射中只是冒星星)、空盔甲兵、
  揮乾草叉的稻草人隊長(倒下時散成稻草)、黑騎士的劍氣;故事對白與繪本插畫(梅林、狐狸女巫摩根娜只是紫色剪影,
  語氣溫和,沒有威脅或恐怖的畫面);打完第一章可以選困難模式。
- **沒有血**、沒有斷肢、沒有死亡畫面:敵人被打倒時倒下消失;黑騎士被打敗時盔甲散落,裡面是空的。
- 狗不會受傷(DEV_PLAN 規則 11):金毛受擊時冒星星,失敗時趴下睡著。
- 沒有恐怖內容、沒有性內容、沒有粗話、沒有煙酒毒品、沒有賭博、沒有抽卡或戰利品箱。
- 沒有聊天、沒有使用者自製內容、不分享位置、不連網、沒有廣告、沒有內購。

## Google Play(IARC 問卷)

位置:Play Console →「應用程式內容 → 內容分級」。類別選「**遊戲**」。

| 題目類別 | 建議答案 |
| --- | --- |
| 暴力 | **是**:卡通 / 奇幻角色之間的暴力;對象是非寫實、非人類的奇幻角色;**沒有**血腥、沒有寫實暴力、沒有對人類或動物的暴力(金毛不會受傷) |
| 恐懼 / 恐怖 | 否 |
| 性內容 / 裸露 | 否 |
| 粗話 | 否 |
| 管制物質(菸、酒、毒品) | 否 |
| 粗俗幽默 | 否 |
| 賭博 / 模擬賭博 | 否 |
| 使用者之間的互動或溝通 | 否 |
| 分享使用者位置 | 否 |
| 數位商品購買 | 否(原型沒有內購;M4 若加入要改「是」) |
| 不受限制的網路存取 | 否 |
| 戰利品箱 / 隨機付費獎勵 | 否(升級時三選一的把戲不用付費) |

預期結果(估計):ESRB **E(Everyone)** 或 E10+(輕度奇幻暴力)、PEGI **7**(非寫實的奇幻角色暴力;若被判為「很輕微的卡通暴力」可能是 3)、
USK **6**、澳洲 **PG** 或 G、IARC 通用 **7+**。

## Apple(App Store Connect 年齡分級)

位置:App Store Connect →「App 資訊 → 年齡分級」。

| 題目 | 建議答案 |
| --- | --- |
| 卡通或奇幻暴力 | **不常 / 輕微** |
| 寫實暴力 | 無 |
| 長時間、寫實的血腥暴力 | 無 |
| 恐怖 / 驚嚇主題 | 無 |
| 粗俗或低俗幽默 | 無 |
| 成熟 / 暗示性主題、性內容、裸露 | 無 |
| 粗話 | 無 |
| 酒精、菸草或藥物 | 無 |
| 醫療資訊 | 無 |
| 模擬賭博、競賽 | 無 |
| 不受限制的網頁存取 | 否 |
| 使用者自製內容、訊息、聊天 | 否 |
| 廣告 | 否 |
| 年齡驗證 / 家長控制 | 否(原型沒有這些功能) |

預期結果(估計):**9+**(不常 / 輕微的卡通或奇幻暴力)。若 Apple 判定打鬥極輕微,可能是 4+。
若目標是讓更年幼的兒童也能下載,M4 時要和「目標年齡」一併決定(`docs/STORE_RELEASE.md` 第 4 節)。

## 甚麼時候要重填

加入內購(數位商品購買)、廣告、聊天、網路功能,或內容變得更暴力(例如加入寫實的武器效果、血)時。
